সৌমিক ডিজিটাল সেন্টার — HTML / CSS / JavaScript

চালু করুন: ZIP খুলে index.html ফাইলটি ব্রাউজারে খুলুন।
হোস্টিং: পুরো ফোল্ডারটি একসাথে আপলোড করুন। কোনো React, npm বা build দরকার নেই।

ফাইল:
index.html — পৃষ্ঠার লেখা, যোগাযোগ, ঠিকানা ও অন্যান্য অংশ।
styles.css — রং, ডিজাইন ও ছোট পর্দার বিন্যাস।
script.js — সেবার তালিকা, মোবাইল মেনু ও লোগো স্লাইডার।
assets/ — লোগো, কভার ও ব্যাংকিং লোগোর ছবি। ফোল্ডারটি অবশ্যই সাথে রাখুন।

“এক জায়গায়, আপনার সব সমাধান” অংশ সম্পাদনা:
script.js-এর শুরুতে const SERVICES অংশে heading, description ও items সম্পাদনা করুন।
প্রতিটি item-এর title, text, icon, tone ও href পরিবর্তন করা যায়।
নতুন সেবা যোগ করতে একটি item কপি করুন; বাদ দিতে item মুছুন।
কমা এবং উদ্ধৃতিচিহ্ন ঠিক রাখুন।

Lovable-এ একই অংশ সম্পাদনা করতে: src/data/services.json
স্লাইডারের অংশ: src/components/BankingSlider.tsx

সব ছবি স্থানীয় ফোল্ডারে আছে। শুধু Google Fonts-এর জন্য ইন্টারনেট দরকার;
ইন্টারনেট না থাকলে ব্রাউজারের উপলব্ধ বাংলা ফন্ট ব্যবহার হবে।
